# 个人随笔集

学生随笔的移动端阅读展示页（静态单页，零外部依赖，移动端优先排版）。

| 文件 | 内容 |
|------|------|
| `index.html` | 文章列表首页（入口） |
| `dongpo.html` | 《湖光晓悟东坡》——西湖晨记，从淡妆浓抹里读懂苏轼的一生 |
| `baobei.html` | 《我的宝贝》——一件磨破袖口、留有奶渍的大红冲锋衣，一本纪念册 |
| `gandong.html` | 《感动的瞬间》——乡村医生爷爷藏起来的秘密 |
| `zhencang.html` | 《值得珍藏》——一只泰迪熊，圣诞夜失而复得的月光 |
| `zuqiu.html` | 《满是伤痕的足球》——一颗旧足球，小学时代的友谊与一场迟到的邀约 |
| `baowu.html` | 《我的宝物》——一方玻璃鱼缸，游着小鱼，盛着阳光与爱 |
| `.nojekyll` | 禁用 Jekyll 处理 |

## 在线访问

```
https://guangdianxiaoshu-bit.github.io/huguang-dongpo/
```

## 本地预览

直接双击 `index.html`，或：

```powershell
python -m http.server 8000 --directory .
# 打开 http://localhost:8000
```
